DotWatcher — Session Join Request Flows

How a viewer discovers, requests, and joins a session — and how the owner handles it.

Browse & Request to Join — Viewer (P7)

Seeing & Handling the Request — Owner (PP)

flowchart TD A([PP is using the app]) --> B{Is PP\ntracking?} B -- Yes, tracking --> C[Location POST every 15s\nresponse includes pendingJoinRequests count] C --> D[Badge appears on\nManage members button] D --> E B -- No, not tracking --> E[PP opens Manage members manually] E --> F[Sheet opens and loads\nGET /sessions/PP-2206/join-requests] F --> G[P7's request shown\nin Pending Requests section] G --> H{PP decides} H -- Approve --> I[POST .../join-requests/id/approve] H -- Deny --> J[POST .../join-requests/id/deny] I --> K[P7 added as viewer member\nRequest marked approved] J --> L[Request marked denied\nNo membership created] K --> M([Member list refreshes\nP7 now visible in Members]) L --> N([Request removed from list]) style A fill:#fef3c7,stroke:#fcd34d style D fill:#fef3c7,stroke:#fcd34d style K fill:#dcfce7,stroke:#86efac style L fill:#fee2e2,stroke:#fca5a5 style M fill:#dcfce7,stroke:#86efac style N fill:#f1f5f9,stroke:#cbd5e1
3

After Approval — Viewer (P7)

flowchart TD A([Session sheet is open]) --> B[Auto-refresh loop\nGET /me/sessions every 10s] B --> C{PP-2206 now\nin memberships?} C -- Not yet --> D[Wait 10 seconds] D --> B C -- Yes, approved --> E[PP-2206 appears in\nSessions list at top] E --> F[Request button disappears\nfrom Browse section] F --> G[P7 taps PP-2206 in Sessions list] G --> H[Session selected\nrole: viewer] H --> I[Sheet dismisses] I --> J([P7 can open the map\nin their browser]) style A fill:#dcfce7,stroke:#86efac style E fill:#dcfce7,stroke:#86efac style J fill:#dbeafe,stroke:#93c5fd
