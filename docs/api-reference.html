DotWatcher — iOS API Reference

All network calls made by the iOS app to the DotWatcher REST API.

Base URL: https://dot-watcher.skelstar.io/api  ·  Auth: Bearer token in Authorization header  ·  Token stored in Keychain

Sections

  • Authentication
  • Sessions
  • Members
  • Location Tracking

Authentication

POST /auth/login No auth

Sign in with username and password. Returns a bearer token and user profile stored in the app for all subsequent calls.

Request Body

{
  "username": "string",
  "password": "string"
}

Response — AuthSession

{
  "accessToken": "string",
  "user": {
    "userId": "string",
    "username": "string",
    "displayName": "string"
  }
}
POST /auth/register No auth

Create a new account. Returns the same AuthSession structure as login — the user is immediately signed in.

Request Body

{
  "username": "string",
  "password": "string",
  "displayName": "string"
}

Response — AuthSession

{
  "accessToken": "string",
  "user": { ... }
}
POST /auth/logout Bearer token

Revoke the current access token on the server, then clear it from the Keychain. Called when the user signs out.

Request Body

Empty

Response

Empty / ignored

DELETE /me Bearer token

Permanently delete the authenticated user's account and all associated data.

Request Body

Empty

Response

Empty

Sessions

GET /me/sessions Bearer token

Load all sessions the current user belongs to, including their role and the invite code for each. Called on app launch, after sign-in, and whenever the session sheet opens.

Request Body

None

Response — [SessionMembership]

[{
  "sessionId": "string",
  "sessionName": "string",
  "inviteCode": "string",
  "role": "owner" | "runner" | "viewer",
  "displayName": "string"
}]
POST /sessions Bearer token

Create a new session. The caller becomes the owner. An invite code is generated server-side and returned in the response.

Request Body

{
  "sessionName": "string | null",
  "displayName": "string | null"
}

Response — SessionMembership

{
  "sessionId": "string",
  "sessionName": "string",
  "inviteCode": "string",
  "role": "owner",
  "displayName": "string"
}
POST /session-invites/{inviteCode}/join Bearer token

Join an existing session using a 6-character invite code (uppercase). Returns the new membership with role assigned by the owner's settings.

Request Body

{
  "displayName": "string | null"
}

Response — SessionMembership

{
  "sessionId": "string",
  "sessionName": "string",
  "inviteCode": "string",
  "role": "runner" | "viewer",
  "displayName": "string"
}
DELETE /me/sessions/{sessionId} Bearer token Owner only

Permanently delete a session and all its members and locations. Only callable by the session owner.

Request Body

Empty

Response

Empty

Members

GET /sessions/{sessionId}/members Bearer token Owner only

Load all members of a session with their roles and display names. Called when the owner opens the Member Management sheet or selects a session.

Request Body

None

Response — [SessionMember]

[{
  "userId": "string",
  "role": "owner" | "runner" | "viewer",
  "displayName": "string"
}]
POST /sessions/{sessionId}/members/{userId}/role Bearer token Owner only

Change an existing member's role (e.g. promote a viewer to runner, or demote a runner back to viewer). Returns the updated member record.

Request Body

{
  "role": "runner" | "viewer"
}

Response — SessionMember

{
  "userId": "string",
  "role": "runner" | "viewer",
  "displayName": "string"
}

Location Tracking

POST /location Bearer token Every 15 s

The core tracking call. Sends the runner's current GPS position to the server during an active tracking session. Fires every 15 seconds, aligned to epoch-based intervals. The response returns all current participant positions — this is the only way the app polls for live session state while tracking.

Request Body

{
  "runnerName": "string",
  "sessionId": "string",
  "latitude": number,
  "longitude": number,
  "heading": number,   // omitted if < 0
  "timestamp": "ISO8601"
}

Response — LocationPostResponse

{
  "participants": [{
    "runnerName": "string",
    "latitude": number,
    "longitude": number,
    "heading": number,
    "timestamp": "ISO8601"
  }]
}
Role requirement: Only users with role owner or runner can post location updates.
POST /location Bearer token

Presence announcement — same endpoint as the tracking call, but sent once immediately when the user selects a session. Sends zero coordinates (lat: 0, lon: 0) so the server registers the user as active in the session before tracking starts.

Request Body

{
  "runnerName": "string",
  "sessionId": "string",
  "latitude": 0.0,
  "longitude": 0.0,
  "timestamp": "ISO8601"
}

Response

LocationPostResponse (ignored)

GET /locations/{sessionId} Bearer token

Fetch the current positions of all participants in a session. Called once when the user selects a session to pre-populate the map before the tracking loop begins.

Request Body

None

Response — [[RunnerPositionResponse]]

[[{
  "runnerName": "string",
  "latitude": number,
  "longitude": number,
  "heading": number,
  "timestamp": "ISO8601"
}]]
Response is an array of arrays — each inner array is one runner's position history (most recent first). The outer array groups by runner.
