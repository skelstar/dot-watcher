The group tile shows on the main screen whether or not you're tracking (mock-up 0a), so the question is what tapping it does when you're not out yet, and whether an invite link can join you from somewhere else. Recommendation: B now, C later. B is what races need (sign up the night before, arrive, press Go) and costs one extra state on the main screen. A is simplest but blocks race sign-up. C is the same join flow with a second button, and can be added once groups exist; it's a separate decision for the organiser (allow watchers or not).
