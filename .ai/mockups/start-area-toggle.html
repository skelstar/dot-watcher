Who can see me: start area

A third row on the card for the 300 m "hidden start area". Today it is silent: strangers don't see you until you are 300 m from where you began, and nothing says so. The new row names it and lets you turn it off.

  • Default stays on, so nobody's start is exposed until they choose.
  • Crew are unaffected: they already see everything, from the first position.
  • Needs a per-account column (like casual_visible_to_non_crew), exposed in /me/casual/settings, and checked in CasualVisibility.ForViewer against the runner's setting, since it is their start being protected. Old clients leave the field out, so it stays on.
  • The same wording could go in the "Before you go" sheet, since that is where a first run starts.
