Arrow or double chevron on Go

The current arrows, double chevrons on every sign, and a different icon for each sign. Each new icon runs from the top of the sign’s title to the bottom of the line under it. Only Go’s nudges. Press and hold a Go sign to see it stop while the sign fills.

What changes with the chevron

  • On Go it is about twice the arrow’s height, so it reads as part of the sign’s lettering rather than an icon beside it.
  • Join and Create get the same shape, sized to their own lettering, and stay still. Go is the only sign that moves.
  • With an icon per sign, each icon says what its sign does: chevrons to head off, an arrow going in to join a run, a plus to make a new one.
  • The event sign isn’t shown here. It would take a still chevron the same way.
