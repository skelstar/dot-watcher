What’s new on the start screen

Two places for the tile, and the list it opens. Tap a tile to open the list; closing it hides the tile until the next update, as it would in the app. The notes are examples.

How it would work

  • The phone remembers the version it last ran. After an update, it asks the server for notes on every version after that one, for its own platform.
  • The tile only appears when that list isn’t empty, and goes away once the list has been opened.
  • Skipping versions is fine: someone going from 1.4.0 to 1.4.2 sees both 1.4.2 and 1.4.1, newest first.
  • New installs don’t see it.
