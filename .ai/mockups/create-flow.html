Steps

  1. Name: with quick ideas to tap
  2. When & how long: start now or schedule; length as chips
  3. Who can see who: drawn with named and grey dots
  4. Options: map pins and replay
  5. Course: optional GPX upload; a new upload replaces the old one
  6. Share: code, QR, link, plus optional group link / staff code for Crew and Race. The session is created when you leave step 5

Step 3 follows the privacy concept (named vs grey dots). The options on step 4 are suggestions to react to, not committed scope. The group link and staff code are optional extras on the share step, for Crew and Race only (staff code for Race only).

Create flow: one scrolling page

The same content as a single form instead of steps. Sections run top to bottom, and Create session stays pinned at the bottom. Scroll inside the phone. Start with Create, then use Edit on "Your run" to see the edit path.

What changes

  1. One page, six sections, no Next or Back
  2. Name is the only required field. Create stays disabled until it's filled
  3. Everything else has a default, so a quick run is: type a name, tap Create
  4. Location only decides who sees the run on their main screen. An invite code works from anywhere
  5. The share screen still comes after Create
  6. Editing: once created, the run sits on the organiser's main screen as "Your run" with Edit and Share
  7. Edit opens the same form, filled in. Privacy can only get stricter (looser options are switched off), a new GPX replaces the old one, and "End run now" is at the bottom

Trade-off: fewer taps, and you can see everything at once. But the privacy choice, the one that matters most, is further down the page and easier to scroll past than a step of its own.
