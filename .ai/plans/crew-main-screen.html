Crew on the main screen

A crew is the people you have chosen. It is mutual and belongs to your account. You add someone only with a one-time code they send you: typed, pasted, tapped as a link, or scanned from a QR code with the phone's own camera. Nobody can be searched for. This mock-up shows what is built on iOS and Android; tap through the phone, and use the buttons to jump to a state.

How adding someone works

  • Show my code (QR, code, Share) is on the add screen. The code is for one person: it works once and lasts 24 hours. If several people get it, the first to use it is added.
  • Three ways in, one confirmation. A tapped link, a pasted message and a typed code all end at “Add Maya to your crew? They'll see you too.” Nothing is added until Add is tapped.
  • Scanning is the camera app's job. The QR holds a link, so the phone's camera opens DotWatcher (or the web page with the code, if the app is not installed). The app has no scanner and asks for no camera permission.
  • Crew is mutual. Either of you can remove the other at any time, immediately. The other person is not told.

What it is saying

  • The ring means crew. A circle with a dark ring is someone in your crew, everywhere: the row, the sheet, later the map. The ring is never the only signal: each face is named.
  • Names are nicknames. People see the name you choose (asked when you first show your code, changeable in Settings), or your initials if you skip it. Usernames are never shown.
  • The row is quiet. It sits above Join and Start, and only appears when the server has crew, so an older server shows nothing.
  • “Crew” and “invite” mean different things. Crew is every time; an invite is one session.

Still open

  • What crew can do. Today a crew is only a list. “Crew + invites” (join and view without an invite code) is not built, and would change who can see whom, so it needs its own plan.
  • Remove and Block together? Block already exists and also ends a crew link.
  • Hearing that someone joined. There are no push notifications, so a new member appears the next time the app loads.

Names and people are examples. The QR is an illustration, not a scannable code. Nothing here talks to the server.
